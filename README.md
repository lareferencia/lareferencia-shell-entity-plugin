# LA Referencia Shell Entity Plugin

Entity-specific entity commands plugin for the LA Referencia Shell.

## 🎯 Functionality

Extends the lareferencia-shell with entity management commands for loading, indexing, and maintaining entity data. Provides command-line tools for entity operations and diagnostics.
